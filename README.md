# MarathonSkills — проект по методичке «WinForms» (практические 1–27)

## Что в архиве

```
MarathonSkills.sln                 ← открыть в Visual Studio
MarathonSkills/                    ← проект C# «Приложение Windows Forms (.NET Framework 4.7.2)»
SQL/Практические_7-26_представления.sql  ← представления и данные для БД
```

## Как запустить

1. **БД.** В SSMS откройте вашу базу (в `script.sql` она называется `Wow_Meow`) и выполните
   `SQL/Практические_7-26_представления.sql`. Скрипт:
   - добавляет марафон текущего года `Marathon Skills 2016` (MarathonId = 6, Екатеринбург, RUS) — ПР 13;
   - добавляет 3 вида забега для марафона 2016. Без них список «Вид марафона» в форме 5 будет пустым;
   - создаёт представления `RunnerView2` (ПР 7), `Фильтр Marathon Skills` (ПР 13), `Мои результаты` (ПР 14),
     `runnerManage` (ПР 17), `Предыдущие результаты` (ПР 26).
2. **Строка подключения.** В `MarathonSkills/App.config` замените `Data Source=.` на имя своего сервера
   (например, `.\SQLEXPRESS`). Если база называется не `Wow_Meow`, поменяйте `Initial Catalog`.
3. **Картинки из папки «Ресурсы»** (их не было среди присланных файлов). Скопируйте папки в
   `MarathonSkills/` (рядом с `MarathonSkills.csproj`):
   - `CharityData` (логотипы благотворительных организаций) — ПР 7, 27;
   - `marathon-photos` и `marathon-info.txt` — ПР 23;
   - `map-icons` (значки карты) — ПР 24;
   - `how-long-is-a-marathon-images` — ПР 25.

   Если папок нет, программа всё равно работает: вместо картинок рисуются заглушки, а карта рисуется в коде.
   Если файлы называются иначе, поправьте имена в `Form11.cs`, `Form12.cs` и в свойстве `Tag` у PictureBox на Form15.
4. Откройте `MarathonSkills.sln` и нажмите F5. Запуск идёт с `Form1`.
   Чтобы посмотреть эталонную форму, в `Program.cs` замените `new Form1()` на `new MainForm()`.

Для входа используйте пользователей из таблицы `User`, например:
- бегун — `a.adkin@dayrep.net` / `jwZh2x@p`;
- координатор — `dean.pinilla@gmail.com` / `WQnbEyjo`;
- администратор — `leila.azedeva@mskills.com` / `MvTQ3itX`.

## Чем проект отличается от скриншотов методички

Код взят со скриншотов. Ниже — места, где пришлось отступить.

- **Набор данных.** В методичке `MarathonSkillsDBDataSet` создаёт мастер VS (файл .xsd). Здесь это класс
  `MarathonSkillsDBDataSet.cs` с теми же именами таблиц и TableAdapter-ов, поэтому вызовы
  `this.userTableAdapter.Fill(this.marathonSkillsDBDataSet.User)` в формах совпадают с методичкой.
- **Имя представления.** В тексте методички оно называется «Фильтр Marathon Skills», поэтому в коде класс
  называется `Фильтр_Marathon_Skills`. На скриншоте было `Фильтр_MarathonSkills_2016`.
- **Ошибки методички, которые исправлены:**
  - Form5: в списке видов марафона пересчёт идёт по событию `ItemCheck`. Со старым `SelectedIndexChanged`
    сумма не обновлялась при повторном клике по уже выбранной строке.
  - Form14: фильтры «Марафон» и «Дистанция» применяются вместе. В методичке второй фильтр затирал первый.
  - Form17: в таблицу попадают результаты только текущего бегуна. В методичке выводились все строки.
  - Form31: кроме имени и пароля сохраняется роль.
  - Время забега показывается как чч:мм:сс, а не в секундах.
- **Закрытие программы.** Формы переключаются через `Hide()/Show()`. Поэтому если закрыть крестиком последнее
  видимое окно, программа завершается (`Program.ExitIfNoForms`). Без этого процесс оставался бы висеть.
